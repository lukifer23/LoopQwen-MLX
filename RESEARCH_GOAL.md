## End-to-end decision plan

| Question | Comparison and evidence | Decision |
| --- | --- | --- |
| Can one assistant do useful work for a caller? | Compare to pinned ordinary Base on identical user requests, including live callback arguments, results, final answers, elapsed time and peak memory. On real module follow-ups the qualified tool model completed 12/16 versus 0/16. | Retain the paired failures and per-family counts. Carry an improvement into depth testing only after the registered primary gate passes. |
| Does repeating a layer cause the gain? | Compare equally trained one- and multi-pass checkpoints. The matched induction advantage is 124/128 versus 58/128. The observed two-pass advantage on module conversations was 12/16 versus 6/16 with paired p=0.146. | Attribute the induction gain within its tested domain. The module depth comparison missed its threshold. |
| Does it transfer beyond the original exercises? | Test complete human reading questions, unseen schemas, counterfactual table contents, multi-message dialogues and ordinary next-token predictions. The linked passage reader and raw-text distillation have separate bounded protocols. | A missed domain floor closes the proposed replacement. Preserve the original training and evaluation evidence. |
| Can it process and use at least 128K tokens efficiently? | Verify all native cache positions and actual answers after a changed distant fact, then assess a complete independently authored novel. At 131,080 tokens the direct packed decoder scored 2/2 versus 0/2 in 171.88 versus 391.67 seconds at 25.99% lower peak allocation. | The packed kernel passed all four primary endpoints. Independent offline retention on long prose and shorter requests gates promotion to the register route. |
| Does the complete product preserve earlier capabilities? | Rebuild one offline release, replay the 22 public tool sessions, 200 language generations, 9,328 raw targets and both complete 131K lookups. On one shuffled stream, charge real startup, mode switches, and tool callbacks. | Report strict dominance only if each enrolled family beats Base on accuracy, total time, first-token time and peak allocation. |
| Can another reader check the claims? | Rebuild the manuscript and figures from the immutable registrations, weights, per-item outputs and independent recounts. | Publish the gate outcomes, comparisons lost, and artifact hashes alongside the successful cases. |
