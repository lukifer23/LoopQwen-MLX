# Factual checks for the open assistance review

These checks use the original user requests and published volunteer replies. They were recorded during fitting, before either held arm had finished generating. The registered ordinal grades, preference rule and thresholds apply as written. One volunteer response serves as context, and alternative correct answers earn full credit.

| Request | What a usable answer must address |
| --- | --- |
| Windows XP wallpaper | The default photograph is *Bliss*, taken by Charles O’Rear in Sonoma County, California. Give the title, photographer and place. [UCR Arts collection](https://ucrarts.ucr.edu/education/bliss/) |
| Four children | The wording already identifies Mike as the fourth child. A concise answer suffices. |
| Copy between Debian servers | The laptop can mediate both SSH connections. Current OpenSSH relays remote-to-remote copies locally by default, and explicit `scp -3 -r` requests that behavior. A correct two-step copy through a local temporary directory also works. Check path nesting and whether the proposed command requires the servers to authenticate directly. [OpenSSH manual](https://man.openbsd.org/OpenBSD-7.8/scp.1) |
| Colorado trails | Give several actual Colorado routes with a useful distinguishing feature for each. Check named destinations, trailheads, and one-way versus round-trip distances when an answer volunteers numbers. [National Park Service trail table](https://home.nps.gov/romo/planyourvisit/list_hiking_trails.htm) |
| Valentine poem | Deliver an affectionate poem addressed to a wife after twenty years of marriage. Rhyme or a particular form was optional. |
| TypeScript, npm and Git | A coherent sequence initializes the package and repository and makes the TypeScript compiler available. A local development dependency and project configuration are standard. Check command order and whether execution relies on an unexplained global installation. [TypeScript project installation](https://www.typescriptlang.org/download/) |
| Fermat’s Last Theorem | Explain the integer exponent greater than two and the absence of positive integer solutions. An example at exponent two can clarify the distinction. Check any voluntary historical or proof claims. [Wiles’s original paper](https://annals.math.princeton.edu/1995/141-3/p01) |
| Heating one room in Scotland | Compare the measured electricity cost of heating the occupied room with the fuel cost and efficiency of heating the whole dwelling. Necessary inputs include actual tariffs, room and home demand, duration and boiler efficiency. The user cannot individually disable the radiators. A categorical price verdict needs evidence. [Energy Saving Trust](https://energysavingtrust.org.uk/advice/electric-heating/) |
| F-centres | The volunteer reference mistakenly identifies a cation vacancy. In the usual alkali-halide case an electron occupies an **anion** vacancy. A complete response describes a creation mechanism, such as irradiation, and explains how selective optical absorption changes the crystal’s apparent colour. [Experimental and computational study](https://www.sciencedirect.com/science/article/pii/S0927025617303762) · [Physical Review B](https://journals.aps.org/prb/abstract/10.1103/PhysRevB.102.184108) |
| Stars in cities | Artificial light scattered in the atmosphere brightens the sky and reduces contrast for faint stars. Clouds, pollution or buildings alone miss the central distinction. |
| Matrix transpose | For compatible shapes the order reverses, giving the transpose of B times the transpose of A. No proof was required. |
| Writing a memoir | Help the person begin. A focused question about subject or purpose, or a usable outline or drafting exercise, can meet the request. Avoid inventing a life history for them. |
