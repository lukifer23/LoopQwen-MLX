# Phase 2 architecture and correctness

The experiment keeps the pinned official text backbone, BF16 weights, tied output matrix and one registered instance per pretrained layer. The default graph executes layers 0–9, then 10–15 twice, then 16–23. Adapter selection uses original layer indices. LoRA rank eight on the full six-layer block adds 1,336,320 trainable parameters. Stabilized recurrence adds one scalar. Its sigmoid interpolates between consecutive block outputs. Gradual and mixed depth use the original shared graph at their sampled depth. An update-indexed seed controls depth sampling and a separate deterministic permutation controls example order.

Each execution site owns its attention KV cache or its GDN state and convolution history. The position offset advances once per input token at each site. V2 extends the uncached reference with an explicit attention window for comparison with rotating KV caches. The long-context audit compares every position over the full vocabulary, projects short slabs to bound memory, and also compares six free-running greedy decisions. Its repetitive English input is a numerical probe.

For variable-length generation batches, native BatchKVCache uses each lane's left-padding count for RoPE and its attention mask. Each GDN site masks padded input and advances its own ArraysCache. After prefill, the GDN padding metadata is cleared. Attention retains per-lane offsets for decoding. The short and long requests can end at different times. Measurements bill every decode call until all lanes finish. The independent sequential cost control uses batch one.

The model still uses the MLX native GDN backward only for uncached, unmasked training. Causal right padding permits independent training examples of different lengths in a microbatch. Only scored positions enter the LM head. In a separate two-call GDN probe, the exact reference gradient decomposes into the early-site gradient transported through the later site plus the local late-site gradient. The project checks both contributions for each LoRA tensor. Diagnostic differentiation treats the relevant input cotangent as fixed. Training retains the full gradient path.

## Data and loss

The immutable V2 schema stores one canonical task fingerprint, a numeric gold, a checked derivation and two distinct token streams. Their prompts request either an answer or a derivation ending in a final-answer line. The last prompt token predicts the first response token. EOS is a scored target. Length includes the input positions preceding the targets. Prose uses full causal next-token prediction and independent documents. Normalization divides the summed loss and gradients by the number of contributing target tokens.

The generator checks composed arithmetic against an independent integer expression, generated equation systems against exact Cramer's rule and substitution, modular updates against a closed-form composition, job durations against enumerated paths, and array transformations against direct index mapping. Instance IDs ignore the prompt paraphrase. The three phrases per in-distribution family share task structure. OOD changes phrasing, operand scale and, for applicable families, chain length or transformation. The job generator always includes the preceding job as a prerequisite. Its positive durations make the longest path a chain. It tests accumulation in a graph rendering and provides limited evidence on general branching logic.

Each source's example mixture weight is explicit. The procedural answer/trace choice uses a stable hash. The sampler shuffles, sorts local windows by canonical trace length and then shuffles whole batches. Answer-only and trace runs can therefore visit identical instances when the length limit admits both. The trainer records eligible and excluded counts, visited IDs, actual input and target tokens, padding, source contributions, per-update depth, alpha, memory and timing. At memory pressure the V2 trainer enables checkpointing or stops at a recoverable boundary. Shrinking the scientific cohort mid-run would change the comparison.

The V2 scorer requires a standalone numeric answer or a final labeled line. It recognizes rational, decimal and scientific notation, rejects conflicting marked values and leaves malformed outputs incorrect. The archived historical benchmark retains its first-line rules. Public publisher-provided traces have their calculator annotations checked. The prose training and development/test material come from separate public-domain US editions of two novels. The independent prose score measures this particular literary domain.

## Research scope

The equal-data and inference-compute controls are motivated by the published Qwen recurrence experiments. The current adapters and local token budgets form a smaller comparison. Output interpolation in this project differs from the full-decoder conversion and input mixing in the second paper. Additional exit and teacher losses remain separate research hypotheses.
