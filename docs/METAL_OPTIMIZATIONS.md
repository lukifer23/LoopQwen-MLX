This checkout uses arm64 CPython 3.12, MLX 0.32.4, mlx-metal 0.32.4 and MLX-LM 0.32.2. The wheel versions are locked. The corresponding release sources are [MLX 36969c0](https://github.com/ml-explore/mlx/tree/36969c094354086e15d2a327a9c50feb20b9cf11) and [MLX-LM 93e6d4a](https://github.com/ml-explore/mlx-lm/tree/93e6d4a6447b3080861985947f0820e76fcb957d). ## Gated DeltaNet

The installed Qwen layer calls gated_delta_update with use_kernel set to the inverse of its training flag. The training route walks tokens with gated_delta_ops. The inference route uses MLX-LM's custom Metal implementation on supported shapes. MLX core separately exposes a differentiable primitive. Its compiled source and executed test show that state has shape [batch, value heads, value width, key width]. The installed Python docstring incorrectly includes a time dimension in the state shape. [MLX-LM training issue](https://github.com/ml-explore/mlx-lm/issues/1956) · [Core VJP](https://github.com/ml-explore/mlx/pull/4565) · [MLX-LM backward discussion](https://github.com/ml-explore/mlx-lm/issues/2050)

The training specialization preserves upstream q/k normalization and scaling, causal left-zero convolution history, sigmoid beta, compute_g decay, gated normalization and output projection. Core casts gamma to the promoted q/k dtype. Passing FP32 q and k keeps FP32 decay and state. The resulting activations are cast back to the original query dtype. Upstream and core mask outputs differ at masked positions. A supplied mask, cache, distributed group or evaluation mode dispatches to upstream code. Right-padded training requires no mask inside a causal decoder when only valid predecessors are scored. A local specialization on the original module instance preserves its parameter names. No package-global monkey patch or new Metal shader is involved. [Core implementation](https://github.com/ml-explore/mlx/blob/v0.32.4/mlx/fast.cpp) · [Qwen module](https://github.com/ml-explore/mlx-lm/blob/v0.32.2/mlx_lm/models/qwen3_5.py)

The primitive benchmark compares outputs, final state and derivatives for q, k, v, gate input, beta input, A_log, dt_bias and initial state. It includes random output and final-state cotangents, a small FP32 finite difference, and two model-shaped BF16 cases. The integration probe differentiates every parameter of a real pretrained GDN at layer 10 against the stock training path. Per-input results are in the benchmark JSON. The tiny head shape can use a core fallback. The timing claim concerns the real 16-head, 128-dimensional shape on this Metal device.

## Projection, checkpoints and timing

The large tied LM head is applied only to hidden rows with scored successors. Full vocabulary normalization still applies to every selected row. Core fast cross-entropy returns FP32 losses. The benchmark compares the loss and hidden-state gradient to full sequence projection and FP32 standard cross-entropy. Decode projects only the last prompt position and processes long prompts in 128-token chunks.

The benchmark warms each path, materializes outputs or gradients and synchronizes before measuring a new interval. The forward-plus-backward median includes actual device work and Python graph construction. Reported backward estimates subtract the independently measured forward median. End-to-end trainer rates use the sum of completed update times, including clipping, optimizer update and synchronization. Validation, checkpoint writes and model loading are excluded from those rates. Memory figures are MLX peak allocated bytes. The benchmark also compares checkpointed and ordinary backwards and measures grouped microbatches.

The upstream model already uses fast RMSNorm, scaled dot-product attention and compiled gate transforms. This implementation keeps the measured core GDN VJP, module-level activation checkpointing, and native cross-entropy. It does not compile a separate whole trainer graph for every possible length or sampled depth.
