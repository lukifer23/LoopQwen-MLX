# Verified curriculum selection

Start from the released Phase 7 categorical R624 weights. Hold architecture, fresh AdamW initialization, optimizer schedule, per-pass supervision, total selected examples, depth policy and stratum counts fixed. A second cycle uses each branch's first successor and preserved moments. Only adaptive selection reads actual model probabilities on the disjoint candidate pool. Static selection uses hashes of the same candidates. The external controller fixes every budget, ranking rule, renderer and verifier. [Registration](../experiments/rsi_pilot.json)

Each of the two cycles introduces 256 fresh permutation maps. Each branch selects 128. Start node and cycle-length group are balanced. The fixed fresh development cohort has 128 maps, each evaluated under two shuffles through six exits. The primary metric is sixth-hop terminal accuracy. Third-hop retention is measured on the same maps. A separate 128-map cohort stays sealed. Score candidate rollouts and development validation separately, charge all additional inference and stop at the registered resource or quality boundary.

STaR uses generated rationales for iterative training. Its answer-conditioned retry is outside this pilot. Absolute Zero and R-Zero use learner-relative difficulty to guide task choice. Here the generator is fixed and the selector uses verified Qwen predictions. EvoEnv and AlphaEvolve use executable checks. Our independent successor and one-hot checks remain fixed, and the learner can select only existing approved experiences. ## Follow-up decisions

Seed 719 cleared the equal-update gate. The follow-up freezes a new curriculum seed and disjoint candidate and development maps while retaining the identical installed parent. A separate static branch spends the measured diagnosis overhead on ordinary updates. Both decisions preceded their outcomes. A same-depth distillation comparison requires replication and a positive advantage over the measured-time control. [Follow-up gates](../experiments/rsi_followup.json)

The verified self-training test uses the Phase 7 verbal checkpoint. It samples two unrestricted three-hop responses per training map. Each accepted response must name the three correct successive rooms. A correct last digit alone supplies no rationale target. The yield floor is eight distinct maps out of 16. Only passing yield unlocks the self-generated-versus-gold SFT pair. [Yield protocol](../experiments/rsi_verified_trace.json)
