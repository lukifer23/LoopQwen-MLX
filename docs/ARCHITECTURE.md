# Text backbone and execution schedule

The Phase 5 categorical study reads an eight-state prediction after each application of the shared middle block. The decoder and cache architecture for language generation follows below. [Pointer architecture and diagram](PHASE5_ARCHITECTURE.md)

The MLX-LM loader constructs the text module from the official multimodal configuration. Its sanitizer strips vision and MTP weights, transposes the depthwise convolutions, adjusts RMSNorm weights and respects tied embeddings. Loading uses strict weight matching. The model has 24 decoder layers, width 1,024, intermediate width 3,584 and vocabulary size 248,320. Every fourth layer performs gated grouped-query attention with RoPE. The other 18 use a causal depthwise convolution and a gated delta recurrence. The pinned non-MoE text module has no special quantization predicate. This experiment uses the original precision.

The wrapper registers the text model once. Its schedule contains integer pairs identifying an original layer and an application of the selected span. The default visits layers 0–9, 10–15, 10–15 again, then 16–23. Each visit indexes the same original module, including its adapters. The tied embedding performs the final vocabulary projection. K=1, 2 and 3 execute 24, 30 and 36 decoder layers respectively. The probe compares all pretrained tensor identities and K=1 logits against the stock model. Its JSON also records whole-forward timings. The baseline JSON lists every layer and projection.

Direct recurrence feeds one block output into the next application. Stabilized recurrence learns one sigmoid scalar, initialized to 0.1, interpolating between the previous state and the block's new output after each additional pass. An optional two-endpoint alpha schedule fixes that interpolation during training. These choices differ from the full-decoder embedding reinjection and exit loss explored in *Closing the Loop*. The published short Qwen3.5 fine-tune used full-weight training on approximately 100M reasoning tokens. [There Is No Free Loop](https://arxiv.org/html/2610.42030) · [Closing the Loop](https://arxiv.org/html/2610.00673)

## Cache semantics

A new request constructs an independent MLX-LM KVCache for every attention execution and an ArraysCache with two independent entries for every GDN execution. The latter holds convolution history and FP32 recurrent state. Each site sees the same new token positions once per forward. Each attention module derives its RoPE offset from its own cache. Per-site masks use the same MLX-LM mask constructors as the original decoder. A cache carries its schedule and decoding rejects a depth change mid-request. An optional rotating KV window bounds attention memory and changes context semantics after eviction. Full-context generation uses fresh caches and an explicit token cap.

The parity check evaluates every vocabulary logit at every position, both token-by-token and in chunks of seven. BF16 changes with matrix dimensions and accumulation order. The test applies a per-position relative RMS limit of 3% for K=1/2 and 4% for K=3, with an absolute limit of 1.5 logits. A 49-token K=3 diagnostic repeating full and incremental inference in FP32 gave worst-position relative RMS 0.00000664 and maximum absolute difference 0.000119. The saved BF16 cases agreed on every greedy token. A new unrelated prompt always receives a new cache.
