## Feasibility of broader instruction and tool supervision

The four-layer warm-up gives 16.99% of its equal-turn training weight to nonwhite reasoning tokens. To examine a substantially different source of supervision, we measured 2,214 full assistant turns from a hash-selected 1,024 conversations in four published SmolTalk2 subsets, using the pinned Qwen tokenizer. Only 52/768 multi-turn instruction responses and 32/256 table responses fit the existing 384-token allowance with the complete reasoning and visible answer. The corresponding figures were 677/678 for tool actions and 271/512 for everyday dialogue. Of the 423 tool turns with a prior observation, 180 followed at least one observation exceeding 1,536 tokens. The source uses its own call markup, including a final-answer tool. Training on these raw sequences would mix tool protocols. A future transfer fit would need to preserve real observations, translate complete actions to the deployed schema and handle long demonstrations explicitly. No model was trained or scored in this source audit. The four upstream Parquet files contain 52,554 conversations. No sampled document had an exactly matching normalized user message in the current supervised or evaluation material.
