# Changed answers in complete long documents

This training material contains 32 questions, each asked against two intact upstream revisions. The six inputs range from about 134K to 205K tokens. The 20 locale questions ask for the exact value of a uniquely resolving XML selector in French or Spanish. The 12 build-reproduction questions ask for the version of a uniquely named crate in Deno's real Cargo.lock. Every answer changes across revisions. The file name and question are identical across the two presentations. The questions were generated from structured records. They have no human-authorship claim.

The source verifier reads the exact published bytes, retains the entire file in each official Qwen prompt, and locates the answer at the stated byte and token offsets. A second XML parser independently resolves every selector. The TOML parser verifies the unique package version against the exact declaration in the original text. The final changed crate in each lockfile occurs beyond token 131,072. French and Spanish answers also exercise long separations between earlier evidence and the question near the end of the file. There are no inserted facts, duplicated filler, or truncated passages.

Run `.venv/bin/python -m scripts.long_branch_sources --download` from the repository root to retrieve and verify the six original files and reconstruct all 64 input digests. The receipt includes their pinned GitHub URLs, raw SHA-256 identities, exact case evidence, prompt lengths and common-prefix identities. This is source preparation. None of these answers counts as a model success. The preceding English and Italian tests remain separately archived.
