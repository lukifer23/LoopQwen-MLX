# Calling a service and answering from its recorded results

This source preserves 9,174 complete first service calls, their 51,373 recorded result rows, and the subsequent natural assistant replies from the official Schema-Guided Dialogue training split. It covers 13 methods across 11 domains, including travel, events, flights, restaurants, housing, weather and calendars. Each source can supervise two generation decisions. The first is a named call with its actual arguments after the human dialogue. The second is the natural response after the complete observation. In 3,360 dialogues the original service exposes multiple eligible nontransactional methods.

The source builder verifies the upstream Git tree and each file's blob identity over all 127 training shards and the service schemas. Each utterance and call preserves its original order. A reply is eligible only if it states at least two distinct source field values from the same observed result row, the source dialogue acts attest to those values, and at least one is absent from the prior dialogue. In total, 22,292 fields are attested in the first supporting result row for each reply. The longest complete action or response sequence has 1,674 native Qwen tokens. The source split is imbalanced. Movies contribute six dialogues and events contribute 2,054. Of the 9,174 dialogues, 634 appeared in earlier project work on clarification or action selection.

A separate check reopened the original files and verified every exact prior dialogue, service call, observation and natural answer. It also paired 3,866 disjoint sets of two actual replies under the same service, method and set of attested field names. Each side states at least two attested values absent as complete values from every result row on the other side. Both replies and observations retain their original provenance. These are prospective supervised examples for learning to use an API result. They are separate from the frozen 7,591-turn fit.

Rastogi and colleagues collected these dialogues by combining a simulator with paid crowd-worker paraphrases. These are historical simulated service records. Today's flight, venue and weather services were never contacted. This corpus supplies no live-tool execution score. The project's locked product comparison uses its actual mounted providers. The derivation selects, groups and serializes the publisher's records in Qwen's native message format. Source data and derived records are CC BY-SA 4.0.
