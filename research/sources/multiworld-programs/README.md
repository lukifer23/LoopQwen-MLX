# One human program on three to nine independently annotated tables

A trained model can open the right table and still repeat the same answer after the rows change. To measure how much direct supervision the original source releases can supply, we joined the full first WikiTableQuestions training split to SQUALL's human programs and Pasupat and Liang's independent ratings on changed tables. The result contains 998 question IDs, 994 distinct question wordings and 902 distinct executable SQL statements from 457 original tables. It includes 886 question IDs outside the previous 149-program fit. This is a training resource. The registered 7,591-turn conditional fit uses its original frozen corpus.

The same query must produce the correct singleton on every eligible version of a question. Eligibility uses the original sources, the existing size and rectangularity checks, identical column names and at least three agreeing raters. Across each question there must be at least three distinct human answers. The original gold must agree with both the original table-question collection and SQUALL. All 24 changed-table assessment contexts, normalized questions and table contents are excluded, as are the fresh FeTaQA questions and table contents. Other projects' training runs and upstream language-model pretraining are outside these checks.

Of 1,983 original candidates, 422 had fewer than three distinct human answers after checking the alternate tables. The complete observed scalar failed on at least one eligible version for another 147. Unsupported SQL normalization and source incompatibilities account for the other exclusions. All dispositions are published. The resulting 5,920 executions have 18,034 agreeing human ratings. A second implementation constructed a fresh in-memory SQLite database for each table and independently reproduced every stored scalar. The original row order, complete answer strings and anonymized votes are retained.

An answer of four would satisfy 352 of the 5,920 labels. Even choosing the best constant separately for each question with knowledge of its labels would satisfy only 2,093 and complete zero whole questions. Reporting the table's row count would get 54 individual worlds and three whole questions. The concentration of count and single-table operations limits transfer to other database schemas, joins and non-tabular tools.
