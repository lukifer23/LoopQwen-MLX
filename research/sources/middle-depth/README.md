# Source-balanced middle-span training material

The frozen file contains 288 complete prompt/response token sequences. Each epoch gives 72 turns each to reasoning, tools, conversation and source-document questions. No teacher generated these targets. Every row identifies its original cluster and supervision group. The inventory pins the inputs, tokenizer-compatible derived banks, builder and resulting token file. The two siblings consume the same rows and targets four times. [Inventory](inventory.json) · [Exposure and optimizer](../../diagnostics/middle-depth/fit.json)

The reasoning turns draw on published QuaRTz polarity pairs and project-verified HotpotQA comparisons. Financial turns reuse executed TAT-QA operands, correct results, crossed results and recovered histories. CoSQL examples exercise nonnumeric database lookups. Each available first-divergent foil receives a margin loss in addition to complete-answer likelihood. Follow the linked source directories for authorship, upstream revisions and licenses. [QuaRTz](../qualitative-pairs/README.md) · [Conversational training inventory](../source-copy/inventory.json) · [Receipt construction](../../../scripts/receipt_repair_material.py)

Conversation includes unrestricted OpenAssistant replies, Dolly summarization, and eight original paired rewriting, decision and clarification requests. The documented edits change which detail, exemption, unit or question matters. The eight original turns are distributed under the project's MIT license. OpenAssistant is Apache-2.0. Dolly is CC BY-SA 3.0. The upstream attribution and verified source identities accompany the derivative rows. [OpenAssistant records](../human-assistance/originals.json) · [Dolly source and license](https://huggingface.co/datasets/databricks/databricks-dolly-15k) · [Original edited turns](conversation-edits.json)

The short document curriculum uses complete FeTaQA tables with human references and pairs of FOSDEM 2023 event records. Published session times are cross-checked between the organizer's calendar and XML. Each edited schedule changes the second end time and recomputes both durations and their difference. The original FOSDEM calendar is preserved. FeTaQA is CC BY-SA 4.0. [FeTaQA attribution](../grounded-table-sentences/README.md) · [FOSDEM dual-source verification](../../../scripts/agenda_sources.py)

The separate long-context loss uses the complete *House of the Seven Gables* and FOSDEM 2025 calendar with documented source edits. The development books are *McTeague* and *Anne of Green Gables*. The complete releases, natural questions and original bytes have separate hashes. No development book is a fit source. The older expert LongBench confirmation panel stays reserved.
