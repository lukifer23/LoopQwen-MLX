# Whole human answers and execution-checked programs

The source pool contains 7,591 complete teacher-forced turns. It joins 149 independently executed human SQUALL queries, 176 executable wrong alternatives, 298 answers following actual query results, 149 schema calls, 761 original FeTaQA explanations, 3,072 independent Databricks employee-written instruction responses, 1,024 original GSM8K worked solutions and 2,138 retained assistance or tool turns. The 384 FeTaQA tables are presented inline and after a real mounted read wherever the complete sequence fits. Every retained target includes its original stopping token. See the exact populations, omitted examples, source hashes and tokenizer limits in [qualification.json](qualification.json).

The Databricks records are selected by a fixed hash order from eight published categories. Three original requests per category are reserved for a fresh masked assessment. Among the remaining cases, 384 per category enter training. No reserved instruction or twelve-word sequence from its instruction, reference or context may recur in those Databricks training records. The other source families preserve their independent published splits. Exact normalized historical panel prompts are excluded from training. The 24 held FeTaQA pages and their reference qualifications are recorded separately. Older product requests serve as explicit retention probes. Public availability allows pretraining contamination, and employee answers can be incomplete, dated or subjective. The reviewer must judge the request and source context individually. [FeTaQA source audit](../grounded-table-sentences/README.md) · [Executed SQL and wrong alternatives](../aligned-table-programs/README.md)

Databricks published its human-authored records under CC BY-SA 3.0, revision bdd27f4d94b9c1f951818a7da7fd7aeea5dbff1a. The publisher’s sole split was subdivided locally. IDs preserve zero-based source row numbers. The source fields retain their original text with outer whitespace removed. This collection joins the instruction and optional context with a blank line. GSM8K questions and explanations come from the publisher’s training split. Their inline calculator markup is removed, the tagged last arithmetic operation is checked in both directions, and the original final value becomes the visible answer. This check covers the last operation only.
