# Rule interpretation when the user changes one reply

Saeidi and colleagues collected conversations about rules in source documents. The publisher released the original test annotations in 2024. We joined actual parent and child utterances within each source tree. Each enrolled parent has a human follow-up question. The original source contains two children whose final user replies are “Yes” and “No” to that same follow-up, and whose recorded decisions reverse. Every other input field, including earlier dialogue and the rule text, is identical. The dataset’s hidden evidence annotations never enter the source material published here. The texts represent the historical source task. [Authors’ task description and data](https://sharc-data.github.io/) · [Paper](https://aclanthology.org/D18-1233/) · [Publisher’s field definitions](https://sharc-data.github.io/data.html) · [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/)

After topical and structural screening, the published training partition had 1,487 qualifying echo branches and 264 qualifying branches with reversed polarity. The published test partition had 607 and 78. A fixed hash order, unique rules, source URLs, questions and trees, and balanced polarity selected 96 training rules and 24 test rules. Forty-eight and twelve, respectively, make an affirmative last reply produce a negative final decision. Membership comes from source annotations and precedes any trained-model use. [Source identities and counts](qualification.json) · [Complete selected dialogues](dialogues.json)

A source-only reading of all 24 test rules found contradictions, missing prerequisites and one snippet that supplied only a list of countries. The original question about seeking work abroad, for example, has earlier replies explicitly denying two necessary conditions. Its positive reference does not follow from the supplied excerpt. The original publisher labels and all attempted selections remain in the data. An unqualified Yes/No score on this cohort would reward some unsupported answers. The source review records item-specific reasons for both valid and problematic cases. These annotations cannot support a general improvement claim by themselves.
