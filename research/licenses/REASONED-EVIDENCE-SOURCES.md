# Sources of evidence and explanations

The English premises, English conclusions, formal annotations and labels are drawn from the public FOLIO v0.0 training and validation files by Simeng Han and colleagues. The material is released under CC BY-SA 4.0. The study numbers the original premises and puts them into user-supplied records. Its English prompts omit formal annotations and published answers. [Project and license](https://github.com/Yale-LILY/FOLIO/tree/5d7bb84c7edab3fb358e057d2807f19cf5cf5e2d) · [FOLIO paper](https://aclanthology.org/2024.emnlp-main.1229/) · [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)

The human-written explanations and caption judgments come from e-SNLI by Oana-Maria Camburu and colleagues, based on Bowman et al.’s Stanford Natural Language Inference data. The e-SNLI project is MIT-licensed and the underlying SNLI data is CC BY-SA 4.0. The supervision preserves human explanations and maps the three labels to true, false and uncertain. [Original explanation data](https://github.com/OanaMariaCamburu/e-SNLI/tree/7b585a3f077fdea899780eb0473940522ae44a2e) · [Stanford NLI](https://nlp.stanford.edu/projects/snli/)

The package checks read the original Core Metadata inside the 44 pinned distribution archives in field kit 01. References use the installed packaging implementation to evaluate each publisher's exact Requires-Python declaration. They describe only the declared Python version constraint. The small rehearsal and retention tasks derive from the existing original WikiSQL release and carry its archived BSD notice.

The training-only teacher is the pinned Qwen3.5-4B MLX quantization used in the preceding study. Its generated explanations are identified separately from the original human explanations. The independent Z3 audit checks formal labels after panel selection. The model receives English and real tool returns. [Qwen model](https://huggingface.co/Qwen/Qwen3.5-4B) · [Z3 project](https://github.com/Z3Prover/z3)

The independent proof curriculum uses the training split of the open-world, depth-three ProofWriter release V2020.12.3 by Oyvind Tafjord, Bhavana Dalvi and Peter Clark. Its language is generated from signed rules. We separately derive a least fixed point and render source-numbered derivations from each sampled world. For unresolved claims we test both polarities. The official archive's README specifies hard negation in this split, including tilde in rule antecedents. The source ZIP remains in the local data cache. Rebuilding the sampler uses its pinned 214,185,889-byte original. The study also reads ten disjoint published distributions from the project's existing wheels, recording the complete wheel and metadata SHA-256 for each. [ProofWriter paper](https://aclanthology.org/2021.findings-acl.317/) · [Original archive](https://aristo-data-public.s3.amazonaws.com/proofwriter/proofwriter-dataset-V2020.12.3.zip)

The table-field study uses human-written InfoTabS claims and the original Wikipedia infobox values distributed by Gupta, Mehta, Nokhiz and Srikumar. The original source checkout is pinned at 34e7dc0900a0d861ad62be3d7371d8eb0aace4fe. We joined its original train and cross-domain α3 test rows to the separate human field annotations by Gupta, Zhang, Vempala, He, Choji and Srikumar (Zenodo release 1.0.0, CC BY 4.0). We publish source IDs, judgments, selected field names, counts, observed values and the transformations used to sample tables. The attachments reorient infoboxes into one record per entity. Selection excludes outside-table evidence and preserves each original wording. The 96 bidirectional lookup tables are from the WikiSQL training split, repository revision cffb423077756d04c1bac5bcd45167c86903fbcb. The package inventory preserves PyPI-distributed original METADATA, release URLs, artifact filenames and both release and metadata SHA-256 values. Package descriptions and underlying Wikipedia text retain their source attributions. [InfoTabS paper](https://aclanthology.org/2020.acl-main.210/) · [Pinned data](https://github.com/infotabs/infotabs/tree/34e7dc0900a0d861ad62be3d7371d8eb0aace4fe) · [Human field annotations](https://zenodo.org/records/6578593) · [WikiSQL](https://github.com/salesforce/WikiSQL) · [Python distribution metadata standard](https://peps.python.org/pep-0658/)
