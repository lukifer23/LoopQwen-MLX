the Berkeley Function Calling Leaderboard, Gorilla LLM team (UC Berkeley).
Source: https://huggingface.co/datasets/gorilla-llm/Berkeley-Function-Calling-Leaderboard

The public portion of the grounded tool training set contains adapted transcripts
from Nous Research's Hermes Function-Calling V1, glaive-function-calling-5k.json.
Source: https://huggingface.co/datasets/NousResearch/hermes-function-calling-v1
Revision dae3e1d28cfbcf4b915c04ea1e072030529b4bda. Apache License 2.0.
The original conversations were filtered for read-only calls with typed arguments.
The retained chat messages are reserialized into the local JSON protocol.
Original conversation identifiers are recorded in each training row.
See BFCL-Hermes-APACHE-2.0.txt for the license.

Table-query questions, reference query annotations and Wikipedia table data
come from Zhong, Xiong and Socher, WikiSQL (Salesforce Research, 2017).
The subset includes 24 distinct official test tables. The preparation script
preserves original questions and selects numeric scalar denotations. Column
names are restored on the publisher's SQLite values. The table tool and the
second denotation check on resampled rows were developed for this project.
https://github.com/salesforce/WikiSQL/tree/cffb423077756d04c1bac5bcd45167c86903fbcb
See WIKISQL-BSD.txt and the source repository for attribution.

Arithmetic-program training uses GSM8K human solutions (Cobbe et al., MIT)
from 3101c7d5072418e28b9008a6636bde82a006892c. The data builder verifies their
calculator annotations and turns them into executable arithmetic expressions.
The transfer evaluation includes SVAMP (Patel et al.) and ASDiv (Miao, Liang
and Su, ACL 2020). The ASDiv questions are attributed to Academia Sinica and
provided under CC BY-NC 4.0; they are used exclusively for evaluation.

https://creativecommons.org/licenses/by-nc/4.0/
https://github.com/arkilpatel/SVAMP/tree/78e727689e1c1bebfc4be39c446898e8e10b0518
See GSM1K-LICENSE and SVAMP-LICENSE for earlier project data notices.

Venue-dialogue excerpts, belief-state annotations and Cambridge venue rows

The separate supervised WikiSQL study uses 768 distinct publisher training
tables and 36 additional official test tables. Each target call is executed
and checked against the publisher SQL before training. The same WikiSQL
upstream revision and license above apply to these subsets.

The operand planner also uses MAWPS (Koncel-Kedziorski et al., NAACL 2016).
The 2016 repository collects human language and arithmetic equations from
earlier published datasets. This project restores numeric placeholders,
canonicalizes punctuation and checks the value of the full equation before
training. The rows come from the authors' SVAMP comparison distribution,
cv_mawps/fold0/train.csv, at the pinned SVAMP revision above. Only this
training fold is used. Training questions similar to the external transfer
sources are removed before sampling.
https://aclanthology.org/N16-1136/
https://github.com/arkilpatel/SVAMP/tree/78e727689e1c1bebfc4be39c446898e8e10b0518/data/cv_mawps

TabMWP data are by Lu et al. (ICLR 2023). The 24 evaluation tables, adapted
prompts and corresponding table/question text in the supplements are available
under the source dataset's CC BY-NC-SA 4.0 license. The project selects
free-response questions, renders the tables as text, and adds the shared
calculator instruction. The local training set contains no TabMWP examples.
https://github.com/lupantech/PromptPG/tree/5a1a52214521590b075f545b76a4f5ce666345e3
https://creativecommons.org/licenses/by-nc-sa/4.0/

The document-search comparison uses human questions and answer locations from
SQuAD v1.1 (Rajpurkar et al., CC BY-SA 4.0) and Qasper (Dasigi et al.,
CC BY 4.0). Material builders select questions and render supplied article
paragraphs into UTF-8 files. Qasper article text comes from the respective
paper authors. The panel identifies each paper by title and arXiv identifier.
The outputs include model-generated queries, responses and attributed excerpts.

The first-pass argument-state fit uses SGD by Rastogi et al., AAAI 2020,
distributed under CC BY-SA 4.0. The local derivative selects human-paraphrased
read-only dialogues, converts service definitions and calls to local JSON,
and derives binary supplied/missing labels from the released slot state.
