# Five standard benchmark samples on native MLX

Before scoring either model, enroll the existing update-576 standalone BF16 LoopQwen and the pinned untouched BF16 Qwen Base on 50 distinct items each from ARC-Challenge test, HellaSwag validation, WinoGrande XL validation, OpenBookQA main test and SciQ test. These five datasets have published results on the exact Base model family and cover science examinations, narrative completion, referent resolution, open-book questions and questions with supplied evidence. Keep all sampled items. Select without replacement by sorting split indices by SHA-256 of “loopqwen-standard-4619/TASK/INDEX”, taking the first 50 in that order. Standard scores are descriptive benchmarks independent of selection on the four-family development suite. The eventual selected checkpoint requires its own standard scores if its weights differ.

Use EleutherAI lm-evaluation-harness 0.4.13 for zero-shot raw completion prompts, choice strings and official scoring. For ARC-Challenge, HellaSwag, OpenBookQA and SciQ use character-normalized choice accuracy, also reporting raw accuracy. WinoGrande uses raw likelihood of the common continuation with each alternate antecedent. Every alternative gets its full conditional likelihood under the ordinary vocabulary head. These standard tasks have no chat template, tool, sampled output or reasoning-token cap. Report generative assistant performance separately. No labels enter the model process. Freeze source revision, file SHA, row indices, request and prompt-token identities. Save target token log probabilities so an independent scorer can reconstruct each decision. Check model probabilities against native cross entropy at the first item of every benchmark and ties against the harness.

Run all 250 Base items, wait for process exit, verify the complete Base scores against the official harness, then run the loop from a fresh process. One model in memory. Charge the existing short-stage budget, up to 900 additional worker-seconds across both arms (1,800–2,000 short continuations at measured native prompt throughput). Checkpoint each item, stop on resource, identity or scoring divergence. Report per-benchmark accuracy, paired gains and losses, elapsed time including all alternatives, input and scored tokens, examples per second, peak MLX bytes and disk sizes. Report per-arm Wilson 95% intervals, paired stratified bootstrap intervals (50,000 draws, seed 4619) and exact two-sided McNemar p-values with Holm correction across five comparisons. The descriptive parity margin is two percentage points on the equal-benchmark mean with a paired lower bound above −2 points. Strong per-benchmark evidence requires at least +10 points and Holm-adjusted p below .05. One item is two percentage points within its benchmark. A sample of this size can leave deployment differences unresolved.

The Qwen Base model card has no benchmark result table. Independent BF16 results from YuhuanStudio using lm-evaluation-harness 0.4.13 list ARC-Challenge 40.1%, HellaSwag 54.9%, WinoGrande 60.2%, OpenBookQA 35.4% and SciQ 91.7%. Their hardware, sample sizes and batch sizes differ from this local run.
